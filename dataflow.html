对照 本仓库文件 ↔ 原版 Music Center

真机主库：OmgDseeHxFilter.ax（算法，映像基址常见 0x61BE0000）。建流旁路：Opc*.dll（COmgDseeHxHelper）+ OmgPcMan.dll（设备输出率）。以下地址以 AX 为准，除非标明在 Opc*。

Python 编排层

cli.main(argv)
  → process_track(src, out, out_rate, out_bits)

唯一对外入口。校验路径后委托整曲处理。

  • src输入音频路径
  • out输出 WAV 路径
  • out_rate目标采样率（须与内容同族 1×/2×/4×）
  • out_bits16 / 24 / 32 / float
bridge.set_configuration(src, output_fs, output_bits)
  → (Source, media)

C dsee_fill_source：对照 OpcFlac connect/填表；decode 仍为 ffmpeg。

  • mediarate, channels, bits, codec, vbr, abr
  • Sourcemode…offset，交给 dsee_open_source
出 → Source + media
decode_pcm(src: Path, rate: int) → Path

ffmpeg 解成立体声小端 s32le，采样率保持内容率（不在此升采样）。

  • rate内容采样率 media["rate"]
  • 返回临时 .s32le 路径（用完删除）
出 → 交织 int32 PCM 文件
Kern(source, media, out_bits)
Kern.process_batch(pcm: ndarray[i32], out: ndarray[f32])

持有 mem + HEQ 状态；建流后按块调用 dsee_process_i32（按 hop 对齐截断尾部）。

  • pcm交织 s32，长度 = hops × rs_in × 2
  • out交织 float32，长度 = hops × rs_out × 2

dsee_mem_size() → int

  • out.src / dst工作输入/输出率

出 → mem 上下文出 → Cfg

C · frame 每 hop 主链

典型 44.1→176.4：rs_in=128，n_in=256，rs_out=512，n_out=1024，a3=128，a4=upmode≪7。

dsee_process_i32(mem, ring0,1, hist0,1, &lag, &hidx, delay, gain,
                 pcm, hops, n_in, n_out, a3, a4, out)
→ for each hop:
      dsee_heq(…, in_hop, heq, nframe=n_in/2)
      dsee_frame(mem, heq, n_in, n_out, a3, a4, frame)
      memcpy(out_hop, frame)

入口：交织 s32le → 逐 hop HEQ → frame（dsp + 出口量化）。

  • ring*/hist*/lag/hidxHEQ 跨 hop 状态（整曲保持）
  • delay, gain全通参数（建流时定）
  • pcm交织 s32le
  • hops本批 hop 数
  • n_in / n_out每 hop 交织样点数
  • a3 / a4rs_in / rs_out
  • out交织 float32 结果
int32 交织 in→ heq int32→ float frame→ out

HEQ 全通延迟对齐 · heq/heq.c

dsee_heq(ring0, ring1, hist0, hist1, &lag, &hidx, delay[7], gain,
         const int32_t *in, int32_t *out, int nframe)

六级格型全通 + 干湿混合；采样率不变。左右共用抽头，状态分声道。

  • ring0/1全通环，长度 RING×2=3178 float
  • hist0/1干路历史，42 float
  • lag / hidx写指针，每样点递减回绕
  • delay[0..5]拼 s0..s5 抽头
  • delay[6]干声 hist 偏移
  • gain湿路增益
  • in / out交织 int32，长度 nframe×2
入 int32出 int32（同长）

frame / dsp 扩展核

dsee_frame(mem, const int32_t *in, n_in, n_out, a3, a4, float *pcm)

① in×2⁻³¹ → float；② dsee_dsp；③ 类 76C0：钳位后 iv/2³¹ 写回 float。

  • inHEQ 后 int32，长度 n_in
  • pcm工作缓冲，长度 ≥ n_out；入出同址经 dsp 变长
dsee_dsp(mem, float *pcm, a3, a4)
  if mem[76]:  dsee_f76_frame(mem, pcm, a3, a3, 0)
  if mem[80]:  dsee_f80_pipeline(mem, pcm, a3, a4)

对齐 AX 6C80：按开关串 f76 与 f80 管线；pcm 就地加长到 n_out 侧。

pcm 长度语义：入侧 a3×声道 → 出侧 a4×声道

DSX · 5E60 同率频带 · kern/dsx/band/（mem+76）

dsee_f76_frame(mem, float *pcm, a3, a4, a5)
  gather → biquad → energy → agc → biquad → energy → band → synth
  → 收尾 biquad → writeback → 历史 copy_f

按声道分析/合成高频激励与增益；pcm 交织就地更新。内部乘加走 Ext80（经 x87_* 封装）。

  • mem含槽位、系数、状态的大上下文
  • pcm交织 float，入口为输入 hop
  • a3每声道输入样点数（调用时常 = a3）
  • a4 / a5写回长度相关；dsp 入口传 a5=0
gather / zero_f / copy_f
biquad / energy / agc
band / synth / writeback

静态算子：拆声道、二阶节、能量、AGC、频带增益、对称合成、交错写回。

dsee_pick_level(…)  // codebook.c
码本表 codebook_tab.c

建流时按声道/vbr/码率选 f76 level，装系数；跑帧时已在 mem 内。

DSX · 6750 升采样重建 · kern/dsx/upsample/（mem+80）

dsee_f80_pipeline(mem, float *pcm, a3, a4)
  每声道:
    gather → dsee_upsample(分析) → dsee_biquad → energy4/16
    → agc → dsee_fir21
  band_gain → input_decode
  每声道:
    dsee_upsample×2（合成）→ 写回 pcm[i*stride+ch]
    → 历史缓冲 copy

主升采样/重建：把 a3 输入抬到 a4 输出时间轴，写回交织 pcm。

  • a3每声道输入 hop（= rs_in）
  • a4每声道输出 hop（= rs_out）
  • up来自 mem（Cfg.upmode）
入 float @ 内容率格子出 float @ 设备率格子
// core/dsp.c — 管线算子（算术用 Ext80）
dsee_upsample(h, N, S, x, y, a5, a6)
dsee_biquad(coef, gain, buf, in, state, n)
dsee_fir21(c, stride, in, out)

多相上采样 FIR、二阶节、21 抽头对称 FIR。被 pipeline（及 f76 侧同类逻辑）调用。

Ext80 精度 · ext80/（不是管线）

ext80_from_f64 / ext80_add / ext80_mul / ext80_sub / ext80_to_f32

模拟 x87 80 位扩展精度，保证与真机 AX 乘加舍入位级一致。不改变采样率，不单独成「处理阶段」。

被 f76 的 x87_* 与 core/dsp.c 内部调用

Cfg.f80 / mem+80 = 是否跑升采样管线。Ext80 = 怎么算浮点。二者同名历史遗留已拆开。

写出

write_wav(path, rate=cfg.dst, data: float32 交织, bits)

把 [-1,1] float 写成 16/24/32 整型 PCM WAV（无 float 出口）。
